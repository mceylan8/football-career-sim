# Football Career Sim

Roguelike Fußball-Karriere-Simulator im Browser (React + Vite + Zustand).
**Schnellkarriere**: eine Entscheidung pro Saison, dann wird die Saison simuliert, danach kommt das Transferfenster.

Vollständiger Projektkontext: [`PROJECT.md`](./PROJECT.md)

## Entwicklung

```bash
npm install
npm run dev
npm run build
```

Deploy: Vercel baut automatisch jeden Push auf `main`.
